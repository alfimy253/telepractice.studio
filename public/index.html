05

Environment variables.

The downloaded package includes a ready-to-use .env file.

ADMINISTRATOR ACCOUNT

The generated site uses these credentials at its date-based owner dashboard. The password is salted and hashed before it is put in the environment file. It is never embedded in the public website.

DATABASE CONNECTION

Paste it exactly as Neon gives it to you, including ?sslmode=require&channel_binding=require if present — the builder strips those query parameters automatically, because the generated app's Neon HTTP driver doesn't use them. Leave this blank to fill in DATABASE_URL yourself after downloading.

Account security

Your username, owner email, salted password hash and a fresh CSRF_SECRET are written to the ready-to-use .env file. The builder generates the ZIP in memory and does not retain the database URL or password.
